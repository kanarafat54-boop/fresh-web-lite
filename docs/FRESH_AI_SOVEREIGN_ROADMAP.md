# #TRUEMODE — Fresh AI Sovereign Intelligence Roadmap

## North star
Fresh AI is the platform's sovereign intelligence layer. Core reasoning must function without a ChatGPT, Gemini, Claude, or other provider API key. Platform agents remain operational managers and execute specialized workflows through Fresh AI.

This does **not** mean pretending that every scientific or computational capability is magically available in one model. Fresh AI owns the intelligence interface, reasoning, memory, truth boundary, planning and orchestration; native algorithms, local engines, Fresh services and explicitly permitted tools provide concrete computation.

## Layer 1 — Native Intelligence Core
- Intent understanding
- Context assembly
- Symbolic and semantic reasoning
- Planning and decomposition
- Constraint solving
- Causal and counterfactual reasoning
- Confidence calibration
- Unknown detection
- Contradiction preservation
- Explanation generation

## Layer 2 — Truth and Knowledge Fabric
- Evidence records
- Claim extraction
- Source provenance
- Temporal validity
- Knowledge graph
- Contradiction graph
- Confidence model
- Known/probable/uncertain/contradicted/unknown/blocked states
- Truth Decision Orchestrator

## Layer 3 — Universal Memory
- Personal memory
- Cross-app memory
- Project memory
- Media memory
- Conversation memory
- Preference memory
- Explicit forget controls
- Memory provenance and correction

## Layer 4 — Skill Fabric
Fresh AI composes reusable skills rather than duplicating reasoning inside agents:

`intent → skill discovery → composition → plan → reason → verify → act → observe → learn`

Initial skill domains include reasoning, research, code, architecture, UI/UX, mathematics, science, security, media, data analysis, translation, optimization, learning and automation.

## Layer 5 — Platform Agents
- Wallet Agent
- Feed Agent
- Security Agent
- Research Agent
- Architecture Agent
- Backend Agent
- Frontend Agent
- Testing Agent
- Documentation Agent
- Deployment Agent
- Media Agent
- Learning Agent

Agents coordinate work. They do not become separate AI providers.

## Layer 6 — Native creation and engineering
Fresh AI should understand and operate on Fresh projects as structured systems:
- repository inspection
- code generation and review
- database/schema reasoning
- UI/component generation
- test generation
- performance analysis
- security analysis
- deployment planning
- media creation and transformation

## Layer 7 — Scientific and analytical domains
Provide native reasoning and tool interfaces for mathematics, statistics, physics, chemistry, biology, simulation planning, forecasting and data analysis. Domain-specific high-compute tasks must be routed to concrete engines/tools rather than falsely represented as pure language reasoning.

## Layer 8 — #TRUEMODE safety and agency
- Explain why a decision was made.
- Show evidence where available.
- Preserve disagreement.
- Admit unknowns.
- Never fabricate provenance.
- Require approval at sensitive action boundaries.
- Keep financial authorization behind the trusted Treasury boundary.
- Let users inspect, correct and forget memory.

## Layer 9 — Evaluation
Every capability needs:
- unit tests
- integration tests
- end-to-end tests
- adversarial tests
- regression corpus
- truth/calibration benchmarks
- latency/resource measurements
- agent-action safety tests

## Implementation order
1. Stabilize `FreshIntelligenceEngine` interfaces.
2. Build native context + intent + claim/evidence structures.
3. Implement Truth Decision Orchestrator.
4. Implement memory fabric and provenance.
5. Implement Skill Fabric.
6. Connect existing agents to the engine.
7. Add native engineering and media capabilities.
8. Add scientific/computational tool interfaces.
9. Build evaluation harness and production observability.
10. Expand capabilities without changing the sovereign contract.

## Non-negotiable API-key rule
The Fresh AI core must boot, reason over its available local/contextual inputs, explain, plan and coordinate without provider API keys. Optional external tools may exist only behind explicit adapters and must never become a hidden dependency of core Fresh AI behavior.
