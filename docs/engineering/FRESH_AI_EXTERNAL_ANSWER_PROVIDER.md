# Fresh AI answer-provider configuration

Fresh AI's native inference and an integrated third-party answer provider are separate capabilities. Do not describe output from an external provider as generated by a Fresh-trained checkpoint.

## Optional OpenAI-compatible adapter

The API route `/api/ai/ask` can use an explicitly enabled OpenAI-compatible chat-completions endpoint when native Fresh inference is unavailable. Configure these **server-side Vercel environment variables** for the relevant deployment:

- `FRESH_ALLOW_EXTERNAL_ANSWER_PROVIDER=true`
- `FRESH_EXTERNAL_ANSWER_URL`: full HTTPS URL to the provider's chat-completions endpoint
- `FRESH_EXTERNAL_ANSWER_API_KEY`: provider API key; keep it server-only and never prefix it with `NEXT_PUBLIC_` or `VITE_`
- `FRESH_EXTERNAL_ANSWER_MODEL`: model identifier accepted by that endpoint

The adapter sends a single user message with a bounded prompt, limits output, disables redirects, uses a timeout, and rejects non-HTTPS production endpoints and malformed/empty responses. The provider must support an OpenAI-compatible request shape (`model`, `messages`, `temperature`, `max_tokens`) and response shape (`choices[0].message.content`).

The feature is opt-in. If the flag is not exactly `true`, this adapter returns no answer and the gateway retains its normal Fresh-owned inference / truthful fallback behavior. Provider outages are surfaced as errors rather than silently presented as successful generation.

## Release verification

After configuring the values in Vercel, redeploy the preview, then run the Fresh AI live smoke test against that preview. Confirm:
1. `/api/ai/ask` returns HTTP success and `status=completed`.
2. The answer addresses the question and includes the expected Fresh Flow formats when asked.
3. The response's `inference` metadata still reports native Fresh inference accurately; an external answer provider does not mean Fresh weights are trained.
4. A separate production test passes only after the exact production environment has been configured and redeployed.

No credentials belong in this document, source control, or client-side environment variables.
