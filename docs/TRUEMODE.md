# Fresh #TrueMode

## Purpose

#TrueMode is the interaction philosophy for Fresh media: help people explore information without hiding the world behind an opaque engagement loop.

## Core features

- 2D Media Navigation: up/down moves through media; left/right opens context, creator space, related media or evidence.
- Context Lens: source, provenance, timeline and uncertainty.
- Why Am I Seeing This?: transparent recommendation signals and user control over those signals.
- Intent Feed: Discover, Learn, Research, News, Relax and Create.
- Mystery Mode: clue -> context -> connection -> discovery; never fabricate a mystery or fact.
- Perspective Mode: separate official, independent, witness, expert and community perspectives.
- Reality Check: distinguish confirmed, supported, disputed and unknown.
- Deep Mode: Short -> explanation -> full media/article -> notes -> learning path.
- Serendipity Engine: controlled useful distant connections instead of similarity-only recommendations.
- Quiet Feed: reduce pressure, notifications and infinite-scroll mechanics.
- Invisible Mode: browsing that does not permanently change personalization when enabled.
- Forget This: remove an interaction from personalization/memory where supported.
- Memory Echo: surface earlier related encounters and compare what changed.
- Time Lens: origin -> development -> turning points -> current state.
- Future Lens: known -> emerging -> speculative, with assumptions separated.
- Origin Trace: preserve original -> edit -> remix lineage.
- Media Current: follow an evolving story rather than isolated posts.
- Investigation Mode: collect media, documents and evidence into a connected workspace.
- Contradiction Detector: surface disagreements instead of silently resolving them.
- Story Weaver: combine posts, Shorts, News, Videos and documents into a source-preserving timeline.
- Question Generator: suggest useful questions the user may not have considered.
- Rabbit-Hole Navigator: choose a deliberate path through a topic.
- Hidden Door: reveal legitimate connections that are not obvious from the current item.
- Unknown Layer: explicitly show what is not established.
- Take Me Somewhere Unexpected: bounded surprise discovery.

## Media relationships

Shorts, long videos, posts, News, Live, Stories, Photos, Audio and Articles should share a common media identity while retaining type-specific behavior.

Key paths:

- Long Video -> Short -> original video
- News -> Short -> full story
- Live -> highlight -> Short -> replay
- Post -> related media -> context
- Media -> source -> provenance -> discussion

## Safety and trust rule

Mystery, discovery and AI explanations must never imply evidence that does not exist. Unknown information remains unknown, and inference must remain distinguishable from source-backed fact.
